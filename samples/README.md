# サンプル文書

チェッカーの動作確認用に、架空サービス「ノートポケット」（架空の株式会社サンプルワークス）の文書を置いている。
各文書には検出されるべき欠陥を意図的に仕込んである。下表がその正解リスト。

種別の見方：
- **ルール**：スクリプトで機械的に判定できる
- **LLM**：文意を読まないと判定できない

|---|------|------|------|
| S1 | 表記ゆれ「ユーザー」と「ユーザ」が混在 | 4. 料金プランの表見出し | ルール |

| S3 | リンク先ファイルが存在しない `./security-whitepaper.md` | 7. セキュリティ | ルール |
